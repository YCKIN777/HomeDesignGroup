家装 AI 智能体平台 · 整体技术框架
v1 总纲 · 定稿即锁定
一句话：本体系统是记忆的唯一骨架（不加其他记忆方式）；内核锁定、配置定制、数据隔离、语义沉淀、Otter 式读取。Windows 本地单机起步。
前端工作台（简单 Web 页）：登录 → 收件箱（审批队列）→ 客户列表/详情 → 派单 → 看板
API 契约（FastAPI · ≤10 接口）：POST /customers 建档｜GET /customers 列表｜POST /messages 起草｜POST /messages/{id}/approve·reject｜POST /dispatch｜GET /todos｜GET /stats｜GET /health
Agent 运行时（中控 + 子 Agent）：main.py 消息总线（/pause /resume /reject /approve /dispatch）· lead_agent（M1/M2/M3a）· dispatch_agent（M4）· scoring_agent（M6）· sop_agent（M7）· invite_agent（M8）· kb_agent（M9）· llm.py 模型抽象（豆包/Ollama 可换）
内核层（锁定）：workflow.py 状态机（八阶段主干·强约束锁定）· rules.py 规则引擎 · config_loader.py 配置加载器（schema 校验·DOS-DP 式）· bus.py 消息总线
本体系统（记忆唯一骨架 ★）：术语注册表（terms.yaml：id/定义/父类/来源/状态）· 关系白名单（part_of / preceded_by / has_participant / has_responsible / derived_from）· 状态机（workflow.yaml）· 沉淀中心（提炼准入4条·垃圾剔除）· 记忆文件（YAML frontmatter：concept_id/relation/state）
四层记忆（本体驱动 · Otter 读取模式）：L1 即时（session 表·会话内）→ L2 短（messages/followups/audit·30天）→ L3 长（客户画像+配置包+沉淀+知识库·本体结构化）→ L4 文本（memory/ md 文件）
读取：身份必载 → 当前客户自动载 L2 → 提问按需检索 L3/L4（带来源）→ 会话内保持；不引入其他记忆方式
数据层（SQLite·每公司一库）：customers / projects / messages / followups / sedimentation_items / users / audit_log / sessions + company_profiles/壹城精工/（terms·rules·extensions·workflow·manifest）+ knowledge/ + sedimentation/ + memory/
接入层：人工录入 + Excel 导入（兜底）→ 阶段3 M3b 渠道直连（企微/微信）
横切工程件：权限（users·角色矩阵）· 审计（audit_log·人审后发可追溯）· 调度（SOP 提醒轮询）· 指标（24h首联率/响应时长/派单及时率/转化）· 测试（schema单测→Agent单测→全链路验收→指标核对）· 运维（init/backup/health）
回路（结构不动·迭代在扩展点）：壹城试跑 → 提炼（去噪·去重·匿名化）→ 沉淀中心（只收优质·垃圾剔除）→ 分拣评审 → 内核 v0.3 或反哺配置包/知识库；数据隔离 × 语义共享分离
五条总原则：① 结构锁定，迭代只发生在扩展点 ② 一切语义走配置包，代码零写死 ③ 数据隔离不共享，语义提炼进沉淀中心 ④ 记忆本体化：不加其他记忆方式，读取按 Otter 模式 ⑤ 单公司先行（壹城），多租户/上云后置
