平台开发路线图 · 有序推进 v1
示意 · 定稿即锁定
五阶段：资料 → 骨架 → MVP闭环 → 能力增强 → 试跑沉淀。每阶段有模块、有验收，你按阶段准备资料。
阶段 0 · 资料与定稿
· 你准备公司资料（业务规则+样本数据）
· 定稿配置包模板 + 沉淀模板
产出：壹城精工配置包雏形
→
阶段 1 · 骨架搭建
· 数据库（客户CRM/项目表 + 配置库）
· 配置加载器（术语/规则/扩展）
· Agent 运行时骨架（中控+消息总线）
产出：可运行的空框架
→
阶段 2 · MVP 闭环
· 线索归集/建档
· 统一收件箱（AI起草→人审批→发送）
· 派单给设计师（建项目）
产出：获客→派单闭环跑通 ★核心里程碑
→
阶段 3 · 能力增强
· 线索评分分级
· 跟进 SOP 提醒
· 邀约到店
· 谈单知识库挂载
产出：前端智能体功能齐
→
阶段 4 · 试跑与沉淀
· 壹城精工真实试跑（1个月）
· 经验提炼→沉淀中心
· 扩展点迭代（结构不动）
产出：首批沉淀物 + 迭代记录
验收标准（每阶段过线才算完）
阶段2：线索录入→客户建档→AI起草→销售审批→派单 全链路人工走通 阶段3：评分/提醒/邀约/知识库 各功能演示通过 阶段4：试跑1个月，沉淀池≥5条优质提炼物，配置包迭代≥2轮
模块优先级一览
