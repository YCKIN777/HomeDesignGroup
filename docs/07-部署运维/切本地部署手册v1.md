# 切本地部署操作手册（架构契约 Step 7）

> 目标：**零改业务代码**，把 LLM/Embedding/向量库/OCR 从云端切到本地。
> 原理：所有模型调用都走 `src/providers/` 抽象层，业务代码只见 `factory.get_providers()`，
> 后端切换只改 `.env` 四个开关。

---

## 1. 四个开关（`.env`）

| 开关 | 值 | 说明 |
| --- | --- | --- |
| `LLM_PROVIDER` | `cloud` / `local` | 主模型（豆包等 / Ollama） |
| `EMBEDDING_PROVIDER` | `cloud` / `local` | 向量化（豆包 embedding / bge-m3） |
| `VECTOR_STORE` | `chroma_local` / `qdrant_remote` | 向量库（文件型 / 集群） |
| `OCR_PROVIDER` | `cloud` / `local` | 多模态 OCR（云 API / 本地占位） |

- 未配置任何 key → Provider 自动降级为 `mock`（可开发调试，数据可运行）。
- 业务代码（agents/kernel/routers）**不感知**后端是云还是本地。

## 2. 本地 LLM（Ollama）

```powershell
# 1. 安装 Ollama（Windows 安装包，装完在托盘运行）
winget install Ollama.Ollama

# 2. 拉取主模型（qwen2.5:14b，约 9GB）
ollama pull qwen2.5:14b

# 3. 拉取 embedding 模型（bge-m3，约 1.2GB）
ollama pull bge-m3

# 4. 验证
ollama list
```

`.env` 切本地：

```ini
LLM_PROVIDER=local
LLM_LOCAL_BASE_URL=http://localhost:11434
LLM_LOCAL_MODEL=qwen2.5:14b
EMBEDDING_PROVIDER=local
EMBEDDING_LOCAL_BASE_URL=http://localhost:11434
EMBEDDING_LOCAL_MODEL=bge-m3
```

> 显存参考：14B 量化版建议 ≥8GB 显存；不足可换 `qwen2.5:7b`（4GB 即可）。

## 3. 本地向量库（Chroma）

文件型 `FileVectorStore`（`data/chroma/*.json`）已可运行；数据量上来后切 Chroma：

```powershell
pip install chromadb
```

```ini
VECTOR_STORE=chroma_local
CHROMA_PATH=./data/chroma
```

> 接口不变：`providers/vector_store.py` 的 `FileVectorStore` 与 `ChromaVectorStore`
> 实现同一接口（add/search/delete），切换零改业务代码。未来集群切 `qdrant_remote` 同理。

## 4. 本地 OCR

真实本地 OCR（如 PaddleOCR）接入点在 `providers/multimodal.py` 的
`LocalOCRProvider.ocr()` —— 接口已定，填实现即可；未接前保持 `MockOCR` 占位输出。

## 5. 切换验收清单

- [ ] `python scripts/verify_providers.py` 10/10 全过（cloud+local 双后端）
- [ ] `python scripts/verify_sentinel.py` 13/13（Sentinel 不因切换后端而失效）
- [ ] `python scripts/demo_agents.py` 10/10（三 Agent 走真实 Provider）
- [ ] 重启服务 `python -m uvicorn api_server:app --port 8000`（WorkingDirectory=src）
- [ ] 冒烟：`http://127.0.0.1:8000/health` + 登录工作台 admin/12345678

## 6. 回滚

改回 `.env` 四个开关即可（cloud），无需动任何代码。切换前后各跑一遍
`verify_providers.py` 对比即可确认无回归。
