## 4. 沉淀中心雏形（垃圾数据处理规则）

### 4.1 提炼准入标准（进池门槛，挡住垃圾）
1. **有真实实例支撑**：来自实际跑系统产生的数据/记录，不是拍脑袋
2. **可复现**：至少 2 家同类公司同样需要，或有权威行业证据（单家特有 → 只进该公司配置包）
3. **不泄露公司**：匿名化 + 抽象化，只保留"模式"，不带公司标识与特征数值
4. **不与内核强约束冲突**：不违背八阶段主干、隐蔽工程不可跳过、人审后发

### 4.2 提炼物格式
```
类别（规则/话术/术语/最佳实践）
标题
描述（模式说明）
适用条件（什么情况下用）
验证证据（实例或行业依据，匿名）
状态（候选 / 已评审 / 已入内核 / 已剔除）
```

### 4.3 垃圾剔除
- 门口挡：不符合准入标准 → 不入池
- 定期复审：季度复审沉淀池，劣质/过时/无实例的提炼物 → 标记剔除
- 数据本身：公司原始数据（客户/报价）永不进池，池里只有提炼物
