# 工作台功能说明（家装 AI 智能体平台）

> 版本：v1.0 ｜ 日期：2026-10-02 ｜ 对应：api_server.py 工作台（10 面板全功能）＋ 九部门视图（编队 v3）＋ 契约线（业主监理三 MVP）
> 本文档基于工作台实际实现整理，操作路径与按钮均可在浏览器实测。

## 一、入口

| 项 | 地址 |
|---|---|
| 工作台（主入口） | `http://127.0.0.1:8000/app` |
| 登录页 | `http://127.0.0.1:8000/` |
| 健康检查 | `http://127.0.0.1:8000/health` |

- 服务为本地 uvicorn 进程（WorkingDirectory = `src`），重启：结束 8000 端口进程后，在 `src` 目录运行 `python -m uvicorn api_server:app --port 8000`。
- 登录：任意手机号进入；角色决定按钮可见性（见文末权限矩阵）。

## 二、十大面板功能详解

### 1. 客户线索（获客前台：M1 归集 / M2 建档 / M4 派单）

| 功能 | 说明 |
|---|---|
| 新建线索 | 手机号必填；姓名/楼盘/预算区间/渠道可填（渠道：小红书/抖音/转介绍…） |
| 批量导入 CSV | 自动去重合并，返回 新建/合并/失败 计数 |
| 查询 | 按 楼盘/姓名/标签 搜索 |
| 状态下拉 | 线索 → 跟进 → 邀约 → 到店 → 派单（逐级迁移，非法跳级拦截） |
| AI 起草 | 一键起草首联消息 → 进收件箱（人审后发） |
| 评分 | M6 评分分级（分数/等级） |
| 邀约 | M8 邀约到店（可填时间） |
| 派单 | 下拉选设计师 → 建项目（P11 起按设计角色动态加载） |
| 详情展开 | 客户档案（楼盘/户型/面积/预算/风格/渠道/标签）＋ 最近沟通记录（L2） |

### 2. 收件箱（AI 起草 · 人审后发：M3a + Sentinel）

- AI 起草的消息汇聚于此，人工**审批发送 / 驳回**（驳回需原因，均审计留痕）。
- 原则：AI 起草永远不直接对外，人审是最后一道闸门。

### 3. SOP 待办（M7）

- 按跟进节奏生成任务（首联 2 小时、跟进 3/7/15 天，规则在 config 包），一键「完成」。

### 4. 项目（派单结果）

- 全部已建项目列表：状态、设计师、创建时间。

### 5. 项目承接（阶段 5 核心工作区）

| 区块 | 功能 |
|---|---|
| 设计方案 | 版本/风格/要点/状态 |
| 报价 | 总额/折扣/状态；**325 项明细**按分部分组展示；单行工程量可改（存，实时更新总额）；**按面积重估**（不覆盖已手动修正行） |
| 付款阶段 | 签约 60% / 阶段验收 35% / 验收 5%：应缴-已收-待收，**登记收款**（金额校验：不超该阶段剩余应缴） |
| 导出 | 报价单 Excel（客户可读） |
| 工程验收 | 五节点：水电/防水/泥木/油漆/竣工（合格/整改/待验收） |

### 6. 业务指标（阶段 4 对账）

- 24h 首联率、响应时长中位数（h）、派单及时率（3 日内）、线索转化率（派单/线索）。

### 7. 谈单知识库（M9）

- 关键词检索（隐蔽工程/全包…），返回标题/来源/片段。

### 8. 契约线 · 业主监理（三 MVP）

| 工具 | 功能 |
|---|---|
| 工艺问答 | 工艺条目（含来源文件）＋ 材料参考价表；草稿态，不对外发送 |
| 报价单生成 | 选业主 → 需求 → 材料分类 → 模板生成（325 条明细）；草稿态，人工确认才发送 |
| 工地日报 | 项目＋监理备注 → OCR＋模板 → 进度摘要；状态 pending_human，人工点发送才对外 |

### 9. 九部门视图（编队 v3）

| 部门 | 功能 |
|---|---|
| 总经办 | 审批汇总（折扣<9.8 折转董事长）、数据看板（累计收款/在建/验收合格）、审计追溯、跨部门协调留痕 |
| 材料 | 按报价 ID 生成**主材清单**、材料库检索（67 项主材实测） |
| 软装 | 家具/灯具/窗帘/布艺/装饰/其他 录入（品名/规格/数量/单价）＋ 清单 |
| 售后 | **质保登记**（整体 2 年/防水 10 年）、**工单流转**（建单→处理→关闭）、回访 SOP 提醒 |

### 10. 权限控制（roles 矩阵）

| 角色 | 能力 |
|---|---|
| 主管 / 董事长 | 全权 |
| 销售 | 起草/评分/邀约/审批/派单 |
| 客服 | 起草/评分/迁移 |
| 其余（设计/材料/财务/行政/项目经理等） | 只读 |

按钮按登录角色动态显隐；对应壹城组织：周乾坤（董事长）、黄旭（设计总监）、杨美华（创意总监/财务）、苏巍（首席设计）、龙晓玲（行政）、范/廖/刘/朱/黄/王经理（项目经理）。

## 三、业务规则挂钩（config 包）

| 规则 | 配置位置 | 实测值 |
|---|---|---|
| 收款比例 | config/rules.payment_stages | 60/35/5 |
| 折扣审批 | config/rules.discount | ≥9.8 折自动批；<9.8 折转董事长 |
| SOP 节奏 | config/rules.sop | 首联 2h / 跟进 3/7/15 天 |
| 质保年限 | config/rules.warranty | 整体 2 年 / 防水 10 年 |
| 开工闸门 | config/rules.gates | 报价有效＋签约款收足 60% |
| 验收节点 | config/rules.inspection | 水电/防水/泥木/油漆/竣工 |

改这些 YAML 即改全平台行为（通用内核＋定制配置双层架构，不碰代码）。
