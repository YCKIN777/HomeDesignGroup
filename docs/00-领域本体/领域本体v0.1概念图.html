本体在平台里的四种用法（这就是"本体论搭架构"的落点）：
① 数据模型：本体概念表 = 主数据 schema——每个 Agent 读写同一套表，不各写各的；
② 状态机：项目生命周期 = 中控 Agent 的路由依据——客户在哪一环，就派哪个 Agent，跨环节自动交接；
③ 规则：报价金额 = 工程量 × 单价、审批门槛等 = 确定性引擎——「算得准」的部分不进大模型；
④ 知识挂载：每个概念下挂资料（材料库、工艺标准、案例库、话术库）= 知识库分类 = 数据需求清单的源头。
