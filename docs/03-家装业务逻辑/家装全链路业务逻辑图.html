家装全链路业务逻辑 · 吃透版 v1
示意 · 行业通用逻辑，公司细节待校准
八阶段主链（前端=①获客→③签约；后端=④材料→⑦售后；⑧横贯全程）
① 获客
渠道投放·留资·首联·邀约到店·量房安排
交付：线索→客户档案
坑：线索跟丢·无效线索·抢单
→
② 量房设计
上门实测·平面方案·效果图/施工图·改稿
交付：户型图·方案（多版本）
坑：改稿无底洞·效果图失真
→
③ 报价签约
工程量·套餐/清单报价·增项规则·合同
交付：报价单·合同
△审批：折扣·优惠
坑：低开高走·增项扯皮
→
④ 材料供应链
选材（业主+设计师）·集采/代购·下单·到货验收
交付：材料订单·进场计划
坑：以次充好·货期延误·色差
→
⑤ 施工工程
交底·拆改·水电·防水·泥木·油漆·安装
交付：工地日报·进度·签证
△审批：变更签证
坑：工期延误·质量事故·返工
→
⑥ 验收交付
四次节点验收（水电/泥木/油漆/竣工）·整改·交付资料
交付：验收单·保修卡·水电走向图
△审批：验收放行
坑：标准扯皮·尾款拖欠
→
⑦ 售后质保
报修受理·派单上门·维修·回访
交付：质保记录·客诉闭环
坑：响应慢·口碑受损·成本失控
⑧ 经营财务（总监办 · 横贯全程）：漏斗·签单额·毛利·现金流·工期达标·满意度·转介绍 —— 所有阶段的数字最终都汇到这里
三条横贯的流（吃透家装，关键看这三条流怎么走）
💰 钱流： 定金（签约）→ 首付（开工前）→ 中期款（水电/泥木节点）→ 尾款（验收交付） （比例因公司而异，待校准）
👥 人流： 市场/销售→ 设计师→ 预算员→ 项目经理/工长/监理→ 售后 （每个交接点都是信息断点，也是 AI 要补的地方）
📋 信息流（= 本体数据主线）： 线索→ 客户档案→ 项目→ 报价/合同→ 材料订单→ 工地/节点→ 验收/质保
行业七大痛点 → AI 平台抓手（每个痛点对应一个 Agent 的主战场）
1 获客贵转化低 → 获客/客服/评分 Agent 2 报价不透明增项扯皮 → 报价 Agent + 增项规则 3 设计周期长改稿多 → 设计 Agent 辅助 4 工地靠人盯信息滞后 → 工程 Agent（日报/照片） 5 材料供应链乱 → 材料 Agent 6 老板看不到实时数据 → 总监办看板 7 售后响应慢口碑损 → 售后 Agent（后期）
