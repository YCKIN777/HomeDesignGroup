# 家装全链路业务逻辑 · 吃透版 v1

> 状态：v1 行业通用逻辑（待壹城精工校准）｜更新：2026-09-29｜存放：HomeDesignGroup/docs/03-家装业务逻辑/
> 用途：这是本体、数据需求清单、Agent 分工的源头。先把业务逻辑吃透，再谈系统。
> 说明：行业惯例数字（付款比例、质保年限等）标注为"惯例，待校准"，以你们公司实际为准。

## 0. 一页看懂

**八阶段主链**：①获客 → ②量房设计 → ③报价签约 → ④材料供应链 → ⑤施工工程 → ⑥验收交付 → ⑦售后质保（⑧经营财务横贯全程）

**三条横贯的流**：
- **钱流**：定金 → 首付 → 中期款 → 尾款（与合同节点绑定）
- **人流**：销售 → 设计师 → 预算员 → 项目经理/工长/监理 → 售后（每个交接点都是信息断点）
- **信息流**：线索 → 客户档案 → 项目 → 报价/合同 → 材料订单 → 工地/节点 → 验收/质保（= 本体数据主线）

**三个审批点**：报价折扣审批（③）、变更签证审批（⑤）、验收放行审批（⑥）

**前端（本阶段）**：①→③；**后端（以后）**：④→⑦。

## 1. ① 获客（前端 · 第一阶段主战场）

| 维度 | 内容 |
| --- | --- |
| 参与者 | 市场/投放人员、销售、客服 |
| 渠道 | 线上投放（抖音/小红书/美团/土巴兔/齐家）、自然到店、转介绍、楼盘驻点/物业合作、老客复购 |
| 关键动作 | 留资 → 24h 首联 → 需求采集（楼盘/户型/面积/预算/风格/时间）→ A/B/C 分级 → 邀约到店 → 上门量房安排 |
| 交付物 | 线索记录、客户档案、需求标签、跟进记录 |
| 钱 | 线索成本（CPL）、到店成本；无直接收入 |
| 数据 | 渠道、来源、楼盘、联系方式、意向度、跟进历史 |
| 常见坑 | 跟进不及时丢单（黄金24h）、无效线索（同行套价/中介）、销售抢单、转介绍无跟踪 |
| 平台抓手 | 线索归集 Agent（多渠道汇总去重）、评分 Agent（真实性+意向）、客服/跟进 Agent（话术+提醒）、邀约 Agent |
| 关键指标 | 线索量 → 有效线索率 → 首联率 → 到店率 |

## 2. ② 量房设计（前端 · 签单临门一脚）

| 维度 | 内容 |
| --- | --- |
| 参与者 | 设计师（+业主、销售陪同） |
| 关键动作 | 上门实测（户型、梁柱、水电点位、采光）→ 原始结构图 → 平面方案（拆改/动线/布局）→ 效果图 → 施工图（水电/天花/立面/节点）→ 改稿定稿 |
| 交付物 | 户型图、平面方案、效果图、施工图、设计说明 |
| 钱 | 设计费（免费引流 / 收费 / 定金抵扣，各公司不同）；设计质量直接影响签单 |
| 数据 | 户型数据、风格偏好、方案版本、改稿记录 |
| 常见坑 | 改稿无底洞、效果图与实际差距大、设计周期拖长导致丢单、设计师忙闲不均 |
| 平台抓手 | 设计 Agent（辅助出方案、案例匹配、风格推荐）、量房排期（派单给设计师的输入） |
| 关键指标 | 出图周期、改稿次数、方案转签约率 |

## 3. ③ 报价签约（前端 · 本阶段终点 + 全链毛利源头）

| 维度 | 内容 |
| --- | --- |
| 参与者 | 预算员、设计师、销售、主管/老板（审批） |
| 报价构成（行业通例） | 设计费 + 施工人工费 + 主材费 + 辅材费 + 管理费（+ 税费，视公司） |
| 计价方式 | 套餐报价（按平米）／清单报价（按工程量）／半包／全包／清包 |
| 关键动作 | 工程量计算（水电/泥木/油漆/吊顶/地面/墙面/门窗/柜体）→ 报价单生成 → 增项规则明确 → 折扣谈判 → 合同签订 → 收款 |
| 交付物 | 报价单、合同、收款记录 |
| 钱 | **定金 → 首付（开工前）→ 中期款（水电/泥木节点）→ 尾款（验收）**（比例惯例，待校准） |
| 数据 | 工程量、单价库、报价版本、折扣、合同条款、收款 |
| 常见坑 | **低开高走**（低价签约后续增项）、漏项、增项扯皮、折扣失控吃毛利、合同条款含糊 |
| 平台抓手 | 报价 Agent（工程量×单价，规则引擎）、签约 Agent（合同草稿+条款检查+收款提醒）、谈单知识库（报价区间/工艺卖点） |
| 关键指标 | 报价转签单率、客单价、毛利率、增项占比 |
| △审批点 | 折扣超阈值 → 主管/老板审批 |

## 4. ④ 材料供应链（后端）

| 维度 | 内容 |
| --- | --- |
| 参与者 | 材料员/采购、设计师（选材）、供应商、项目经理（到货） |
| 材料分类 | 主材（瓷砖/地板/洁具/橱柜/门/窗）、辅材（水泥/沙子/板材/电线/水管/防水） |
| 采购模式 | 公司集采 / 指定品牌 / 业主自购 / 代购 |
| 关键动作 | 选材（业主+设计师确认）→ 比价下单 → 到货验收 → 与施工工序匹配进场 |
| 交付物 | 材料订单、进场计划、验收记录 |
| 钱 | 材料款（含在合同额内则走工程款；自购则业主直付） |
| 数据 | SKU、品牌、供应商、单价、账期、到货时间 |
| 常见坑 | 以次充好、货期延误拖工期、色差/批次差异、供应商跑路、库存积压 |
| 平台抓手 | 材料 Agent（材料库匹配、比价、下单提醒、到货跟踪） |

## 5. ⑤ 施工工程（后端 · 最重管理）

| 维度 | 内容 |
| --- | --- |
| 参与者 | 项目经理、工长、工人班组、监理、设计师（交底/图纸问题） |
| 标准工序（行业惯例） | 开工交底 → 拆改 → **水电（隐蔽）→ 防水** → 泥木（瓦工/木工）→ 油漆 → 安装（主材/灯具/洁具/五金）→ 开荒保洁 → 竣工验收 |
| 关键动作 | 排期、交底、巡检、日报（照片/进度）、节点验收、变更签证、整改闭环 |
| 交付物 | 施工进度、日报、签证单、问题清单 |
| 钱 | 人工费结算、中期款节点触发 |
| 数据 | 工地、进度、节点、照片、问题、签证 |
| 常见坑 | 工期延误（材料/工人/交叉施工）、质量事故、隐蔽工程返工、工地安全、工人难管理、信息滞后 |
| 平台抓手 | 工程 Agent（排期、节点提醒、照片进度分析、验收清单、预警） |
| △审批点 | 变更签证（增项金额确认）→ 项目经理+业主签字 |

## 6. ⑥ 验收交付（后端）

| 维度 | 内容 |
| --- | --- |
| 参与者 | 监理/项目经理、业主、设计师 |
| 验收节奏（行业惯例） | 四次：水电完工 → 泥木完工 → 油漆完工 → 安装收尾/竣工验收；每次只查当阶段，签字后再进下道工序 |
| 验收依据 | GB50327 等国家标准 + 企业标准（资料库 E1/E2 已建档） |
| 关键动作 | 按检查表逐项验收 → 整改 → 复验 → 交付资料（验收单/保修卡/水电走向图/使用说明） |
| 交付物 | 验收单、保修卡、水电走向图、交付说明 |
| 钱 | **尾款结清**（验收通过触发） |
| 数据 | 验收记录、整改记录、交付资料 |
| 常见坑 | 验收标准扯皮、问题整改拖延、尾款拖欠 |
| 平台抓手 | 工程/验收 Agent（清单生成、整改跟踪） |
| △审批点 | 验收放行（业主签字） |

## 7. ⑦ 售后质保（后端 · 后期）

| 维度 | 内容 |
| --- | --- |
| 参与者 | 客服/售后专员、维修班组 |
| 质保条款（行业惯例） | 隐蔽工程约 5 年、整体约 2 年（各公司不同，待校准） |
| 关键动作 | 报修受理 → 派单 → 上门维修 → 回访 → 客诉升级处理 |
| 交付物 | 质保记录、维修单、回访记录 |
| 钱 | 质保期内免费维修（成本）；质保金/尾款涉及 |
| 数据 | 质保档案、客诉、维修工单 |
| 常见坑 | 响应慢、多次维修、口碑受损、售后成本失控 |
| 平台抓手 | 售后 Agent（报修受理、派单、回访提醒）——后期 |

## 8. ⑧ 经营财务（总监办 · 横贯）

| 维度 | 内容 |
| --- | --- |
| 核心指标 | 线索→签单漏斗、签单额、开工率、毛利率、工期达标率、客户满意度、转介绍率、现金流 |
| 资金流 | 定金→首付→中期款→尾款（回款节奏 = 现金流） |
| 决策 | 投放预算分配、报价折扣授权、人员绩效、供应商选择 |
| 数据 | 全链数据汇总（各阶段的关键指标） |
| 平台抓手 | 总监办 Agent：看板 + 预警（毛利/超支/延期/客诉/漏斗异常） |

## 9. 行业七大痛点 → AI 平台抓手（汇总）

| # | 痛点 | 主战场 Agent |
| --- | --- | --- |
| 1 | 获客贵、转化低、线索跟丢 | 获客/客服/评分/跟进 Agent（第一阶段） |
| 2 | 报价不透明、增项扯皮 | 报价 Agent + 增项规则（后端） |
| 3 | 设计周期长、改稿多 | 设计 Agent 辅助（已有原型） |
| 4 | 工地靠人盯、信息滞后 | 工程 Agent（后端） |
| 5 | 材料供应链乱 | 材料 Agent（已有原型雏形） |
| 6 | 老板看不到实时数据 | 总监办看板（横贯） |
| 7 | 售后响应慢、口碑受损 | 售后 Agent（后期） |

## 10. 待壹城精工校准的公司细节（吃透的最后一步）

请对照你们实际情况修订/确认：

- [ ] **报价结构**：你们报价单的构成项、套餐档位、计价方式（半包/全包）是什么？（可参考已有《装修项目估算书2026.xlsx》）
- [ ] **付款比例**：定金/首付/中期/尾款各多少、在哪个节点收？
- [ ] **增项规则**：增项如何定价、谁审批、有没有比例红线？
- [ ] **工序划分**：你们公司施工分几个节点、每个节点验收什么？（可能和行业惯例不同）
- [ ] **质保条款**：隐蔽工程/整体质保年限和范围？
- [ ] **组织架构**：销售/设计师/项目经理/监理的实际人数和分工（决定角色→环节关系）
- [ ] **获客渠道**：当前主要渠道和占比（决定线索归集 Agent 先接哪个）
- [ ] **历史数据**：有没有可提供的历史报价单、合同、工地记录（决定 AI 质量上限）
